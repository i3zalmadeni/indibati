# انضباطي | INDBATI

نظام إدارة الحضور والغياب والتأخر والانضباط المدرسي في **متوسطة لبيد بن ربيعة**، وهو أحد الأنظمة التشغيلية المستقلة ضمن منظومة **النواة الرقمية**.

- **المرجعية المعلوماتية:** النواة الرقمية. الطلاب والفصول والمنسوبون والحسابات تُقرأ منها بالمعرّفات الثابتة (UUID)، ولا تُنسخ.
- **الاستقلال التشغيلي:** للنظام جداوله الخاصة (`ind_*`): التحضير، والتثبيت، والتأخر، والتكليفات، والإعدادات، وسجل العمليات.
- **الدخول:** بحساب النواة نفسه، والجلسة مشتركة مع بقية الأنظمة. لا عضويات جديدة.
- **الهوية:** نسخة من هوية النواة (`core.css` و`chrome.js` وخط Tajawal) مع شعار النظام فقط.

## البنية
| المسار | المحتوى |
|---|---|
| `site/` | واجهة ثابتة (HTML وJS بلا أداة بناء) تُنشر على GitHub Pages |
| `site/assets/ind.js` | المنطق المشترك: الاتصال، الصلاحيات في القائمة، التاريخ الهجري والميلادي، المكونات |
| `site/assets/pages.js` | الصفحات: الرئيسية، التحضير اليومي، التثبيت، التأخر، التكليفات، الإعدادات، سجل العمليات |
| `supabase/migrations/` | ترحيلات قاعدة البيانات (`0301_…`)، قابلة لإعادة التنفيذ |
| `tests/` | اختبارات القاعدة (`run.sh`) واختبارات الواجهة بمتصفح حقيقي (`e2e/`) |
| `docs/` | المعمارية، والتكامل مع النواة، والنشر، وسجل المراحل |

## الأدوار
| الدور | المصدر | الصلاحيات |
|---|---|---|
| مدخل بيانات الغياب | تكليف `absence` | التحضير والتثبيت في فصوله المسندة فقط. لا يعدّل مثبتاً ولا يلغي تثبيتاً |
| مدخل بيانات التأخر | تكليف `lateness` | تسجيل التأخر لطلاب فصوله المسندة فقط |
| منسق الغياب | `ind_staff_roles.coordinator` أو مدير النواة | كل ما سبق لجميع الفصول، وإلغاء التثبيت لأي تاريخ، والتكليفات، والإعدادات، والسجل |
| شؤون الطلاب | `ind_staff_roles.affairs` | اطلاع إشرافي على كل السجلات دون تعديل |
| مدير البوابة | `ind_staff_roles.portal_admin` (يمنحه مدير النواة) | الأدوار وسجل العمليات |
| ولي الأمر | — | المرحلة الخامسة (رابط آمن خاص بالطالب) |

التحقق من الصلاحيات يتم في الخادم داخل كل دالة `ind_*`. الجداول مغلقة بـ RLS دون أي وصول مباشر، ومحاولات الوصول غير المصرح تُسجَّل.

## التشغيل المحلي والاختبار
```bash
# Postgres محلي (16+) ثم:
PGHOST=/tmp/pg PGPORT=5544 tests/run.sh          # اختبارات القاعدة (نسخة هيكلية من النواة + الترحيلات مرتين + السيناريوهات)
# معاينة الواجهة ببيانات وهمية محلية:
psql … -d indibati_e2e -f tests/core_stub.sql -f supabase/migrations/0301_indibati_foundation.sql -f tests/e2e/seed.sql
PGHOST=/tmp/pg PGPORT=5544 node tests/e2e/server.js   # http://localhost:8787
node tests/e2e/run.js                                 # اختبارات الواجهة (Playwright)
```
